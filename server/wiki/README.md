# Wiki 모듈

Aston Wiki 판단 기록을 마크다운 파일로 저장하고 검색하는 독립 모듈이다.

## 책임

- 텔레그램/인텐트에서 전달된 판단 기록을 `WIKI_ROOT` 하위 마크다운 파일로 저장한다.
- frontmatter, 태그, 카테고리, 검색 결과 요약을 관리한다.
- 브리핑 재귀 누적을 막기 위한 `briefing` 항목 필터링 규칙을 유지한다.

## 비책임

- Telegram 메시지 파싱과 라우팅은 `server/intent/` 책임이다.
- 모닝 브리핑 생성은 `server/intelligence/` 책임이다.
- Google Drive API 업로드/권한 관리는 `server/google/` 책임이다.

## 데이터 경로

| 환경 변수 | 용도 |
|---|---|
| `WIKI_ROOT` | Wiki 마크다운 저장 루트. 예: `G:\내 드라이브\Aston-Wiki` |

## 외부 API 의존성

- 직접 외부 API 호출 없음.
- 저장소는 로컬/동기화된 파일 시스템 경로만 사용한다.

## 텔레그램 명령 목록

- `위키 저장 <내용> #태그`
- `위키 검색 <질문>`
- `위키 검색 #태그 <질문>`

## 다른 모듈과의 관계

- 다른 도메인 모듈 직접 import 금지.
- `server/intent/`에서 이 모듈을 호출한다.
- Intelligence 모듈과의 공유는 `WIKI_ROOT` 파일 시스템 경로를 통해서만 한다.

## 주요 파일 목록과 라인 수

| 파일 | 라인 수 | 설명 |
|---|---:|---|
| `wikiStore.ts` | 237 | 마크다운 저장, 검색, frontmatter 처리 |

## 신규 기능 판단 기록

- Wiki 저장/검색/기록 포맷 변경은 이 모듈에 추가한다.
- 브리핑 생성, AI 분류, 외부 수집은 신규/기존 해당 도메인 모듈에서 처리한다.
