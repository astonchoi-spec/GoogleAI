## 3) 집에서 바로 실행 순서 (오류 최소화)

1. `.env` 점검
   - 필수: `REDIS_URL`, `WORKSPACE_SPREADSHEET_ID`
   - 거래소: `GATE_API_KEY`, `GATE_SECRET`
   - 키움: `KIWOOM_BASE_URL`, `KIWOOM_APP_KEY`, `KIWOOM_APP_SECRET`, `KIWOOM_ACCOUNT_NO`, `KIWOOM_HTS_ID`
   - 실시간: `UPBIT_WS_SYMBOLS`, `KIWOOM_WS_*`
   - 웹훅: `TV_WEBHOOK_SECRET`
2. 의존성 설치 확인
   - `pnpm install`
3. 안정성 체크
   - `pnpm run check`
   - `pnpm run build`
   - `pnpm run test`
4. 실행
   - `pnpm run dev`
5. 기능 스모크
   - `/trading` 진입
   - Upbit/키움 realtime status query
   - TradingView webhook health endpoint 확인
